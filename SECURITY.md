# Security policy

Report a vulnerability privately, **not** as a public issue:

- **GitHub Security Advisories** on the repository it concerns (the **Security** tab, then
  **Report a vulnerability**). For the app that is
  <https://github.com/plxnative/plx-native/security/advisories/new>.
- or e-mail **support@plxnative.com** with `PlxNative security` in the subject.

The full policy, with what is in scope and how quickly to expect an answer, is the app's
[SECURITY.md](https://github.com/plxnative/plx-native/blob/main/SECURITY.md). It applies to every
repository in this organization. For the HUD registry, a way to get an unsigned or wrongly signed
index or bundle accepted by the app is in scope.
