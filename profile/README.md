# PlxNative

A fast, unofficial [Plex](https://www.plex.tv/) client for LG webOS televisions. It is native, not a
web page: the interface is drawn straight on the GPU at 60 fps, and video plays on the TV's own
decoder, 4K HEVC and Dolby Vision included. No Chromium, no JavaScript, no web view.

**[plxnative.com](https://plxnative.com/)** · [Install guide](https://plxnative.com/install/) ·

## Getting help

- **Something is broken:** [open a bug report](https://github.com/plxnative/plx-native/issues/new/choose).
- **A question, an idea, or "it works on my TV":** [Discussions](https://github.com/plxnative/plx-native/discussions).
- **A security problem:** report it privately, as the
  [security policy](https://github.com/plxnative/plx-native/security/policy) describes.
